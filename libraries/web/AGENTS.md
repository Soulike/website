# Web Libraries

Browser utilities, rendering packages, React hooks, and reusable React components belong here. Apply the reusable-library boundary described in [../AGENTS.md](../AGENTS.md).

Use the target package's scripts and configuration for validation. Browser utilities retain their own package structure. Application-specific Vite builds, Docker images, and Nginx deployment are configured under `apps/web/`.

When working on React components, read [React conventions](../../docs/agents/react.md).
