# Web Apps

- Use TypeScript, React and Vite.
- Use the application's existing test script and Vitest configuration when testing.
- Built with Docker. Nginx is included in Docker image for static file serving.

When working on React components, read [React conventions](../../docs/agents/react.md).
When working with Ant Design (`antd`), check [Ant Design documentation index](https://ant.design/llms.txt) to look up the relevant documentation as needed.
