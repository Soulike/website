# Web Business Modules

Business logic and React integrations for Web applications belong here. Keep project-specific behavior within the business-module boundary described in [../AGENTS.md](../AGENTS.md).

Use the target package's scripts and configuration for validation. These packages are consumed by applications; application-specific Vite builds, Docker images, and Nginx deployment are configured under `apps/web/`.

When working on React components, read [React conventions](../../docs/agents/react.md).
